# Captions

**House rules:** all caps for announcements, lowercase only for one-word teasers; patois where it hits natural, never forced; fit pics get no caption or one word; every drop/announcement ends WERUNTINGS.; credit SHOT BY / DIRECTED BY; no hashtag walls; don't reply in comments on drop posts.

## Formulas
- Drop post: `JOIN THE ENDZ VIA GRSNWORLD.COM` / `WERUNTINGS.` / `[ GRSNWORLD.COM ]`
- Teaser: `soon come.`
- Drop list: `STORE OPENS FRIDAY 7:00 PM NEW YORK TIME.` / date / one item per line / `WERUNTINGS.`
- Pop-up: `GARRISON YARD POP UP. THIS SATURDAY.` / what's available / date and time / `LOCATION DROP PON DI STORY 10AM SATURDAY.` / `FIRST COME. FIRST SERVED.` / `WERUNTINGS.`
- Tribute: `ARCHIVE 01. MR WACKY.` / `FOR BOGLE.` / `SHOT BY [@HANDLE]` / `WERUNTINGS.`
- Film: `GARRISON. [PIECE].` / `2026.` / `DIRECTED BY [@HANDLE]` / `WERUNTINGS.`
